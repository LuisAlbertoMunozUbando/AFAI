# Automation Foundry AI (AFAI)

Frontend proof of concept for collective intelligence in robotic automation.

Open `index.html` or enable GitHub Pages from `main` / root.

## Features
- Catalog of eight existing IdeaFactory apps, linked directly.
- Role filtering for technicians, engineers, researchers.
- Adopt tool preferences via browser localStorage.
- Local idea capture, JSON export.
- File selection manifest; **no upload or processing**.
- Template-based automation agenda, report, paper and invention disclosure outlines, downloadable as Markdown.

## Limitations
No connected AI backend, authentication, secure file handling, collaborative knowledge graph, verified paper drafting, or patent filing. Avoid confidential documents and IP in this public prototype. Qualified engineers must validate technical decisions.
